Distinction fondamentale

Green IT vs IT for Green

Green IT 🌿
Réduire l'impact du numérique. Faire plus avec moins. 3 piliers : sobriété matérielle, sobriété logicielle, éco-conception.
IT for Green ⚙️
Utiliser le numérique pour aider d'autres secteurs. Ex : smart grids, maintenance prédictive, optimisation logistique.
Le piège classique

Effets rebond

Direct : efficacité gagnée → augmentation de l'usage (écran 4K plus efficient → on regarde plus d'heures).
Indirect : économies réinvesties dans d'autres consommations polluantes (économie chauffage → voyage en avion).
⚠️ Le télétravail n'est vert que sous certaines conditions (distance, logement, équipement).

Quick wins éco-conception Web

Images
AVIF/WebP, srcset, loading="lazy", dimensions explicites (CLS).
JavaScript
Code splitting, tree-shaking, supprimer dépendances. Bundle < 50KB gzip.
Cache + compression
Gzip / Brotli, headers immutables, fingerprint URLs, CDN.
Tiers
Audit des scripts tiers (analytics, ads), self-host les fonts, RUM échantillonné.
